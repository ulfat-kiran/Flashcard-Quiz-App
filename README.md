# Flashcard Quiz App

A simple and interactive Flashcard Quiz App built with React and Vite. It helps users practice and revise information using digital flashcards.

## Live Demo

https://flashcard-quiz-app-weld.vercel.app/

## GitHub Repository

https://github.com/ulfat-kiran/Flashcard-Quiz-App

## Features

* View flashcards with questions and answers.
* Show or hide the answer of a flashcard.
* Navigate between flashcards using Previous and Next buttons.
* Add new flashcards.
* Edit existing flashcards.
* Delete flashcards.
* Reset the flashcards to the default set.
* Save flashcards in the browser using localStorage.
* Responsive layout for desktop and mobile screens.

## Technologies Used

* React
* JavaScript
* Vite
* HTML
* CSS
* Browser localStorage

## Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/ulfat-kiran/Flashcard-Quiz-App.git
```

### 2. Open the project folder

```bash
cd Flashcard-Quiz-App
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.

## How to Use

1. Open the application.
2. Read the question displayed on the flashcard.
3. Click the button to show or hide the answer.
4. Use Previous and Next to navigate between flashcards.
5. Use the available form to add or edit flashcards.
6. Delete flashcards when they are no longer needed.
7. Use Reset to restore the default flashcards.

## Data Storage

The application uses the browser's localStorage to save flashcards. The saved data remains available in the same browser unless the browser storage is cleared or the application data is removed.
